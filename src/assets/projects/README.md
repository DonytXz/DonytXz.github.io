# Project screenshots

The current public-page screenshots were captured on September 27, 2026; the Espacios Escénicos image was supplied by the author. All were approved for the portfolio. The PNGs are the original captures; Astro generates responsive WebP card previews at build time. Clicking a card image opens a native gallery dialog; full images load on demand from local PNGs. Without JavaScript, the image link opens the first PNG directly. Add entries to a project's `images` array to enable its image-count badge and previous/next controls. These screenshots are evidence of the public interfaces, not a claim that all current UI was authored during the contribution periods.

- `tramites-digitales.png`: <https://tramitesdigitales.guadalajara.gob.mx/inicio>, current public homepage. Contribution period: March–June 2022, SONETASOT. The author's 2022 tesina documents Angular interfaces, forms, REST integration and Jest testing (pages 9, 22–24), with historical public screenshots on pages 26–29. The author confirmed PHP, Laravel and PostgreSQL for this project.
- `tramites-digitales-2022.png`: Original public homepage screenshot extracted from page 26 of the author's 2022 tesina. This second gallery image shows the historical interface, separately captioned from the current homepage.

- `pbh-abogados.png`: <https://app.pbhabogados.com/>, current public homepage. Contribution period: January–August 2021, Sharptech. The existing CV documents React frontend leadership, Stripe payments and Nodemailer email workflows. The current site footer credits CILABS; the portfolio describes the author's contribution through Sharptech, not exclusive ownership or ongoing maintenance.
- `pracofi.png`: <https://donatoalvarez.dev/pracofi/>, public interface screenshot captured September 2026. React and Vite application for accounting and tax advisory management, with source at <https://github.com/DonytXz/pracofi>.
